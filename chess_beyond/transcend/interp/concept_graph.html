Chess concept map

Two copies of one chess model that reads games as text, never shown the board: one trained on games between 2400+ players, one on games between 1000–1300 players. This map shows the concepts found inside them, and which concepts one model has and the other lacks.

Lines are concepts

Each model played many games from the same starting positions. Where it could go two ways, we looked inside it (its internal state halfway through, at layer 11) for what separates the move it usually plays from one it plays less. That small, repeatable difference is a concept. Many have a plain chess meaning: trade queens, double rooks, go for a draw.

  • colour: how reliably the concept was found (it comes back when the search is rerun from scratch); brighter = more reliable
  • thickness: how many positions it was found at

Dots are latents

A latent is one small feature of the model's internal state; a concept is built from a few of them, so its line joins the latents it uses (two latents: a line, three: a triangle, one: a short spur). Brighter dots fire more often.

Reading a concept's examples

Each example shows one position twice. Left: the move the model usually plays there, and how the game goes on. Right: a move it plays less often. Teal shading on a move = how strongly the concept is on after it. A good concept is shaded on the left and not on the right. Each side opens on Lichess.

Where to start

Pick a concept under start here: those are labelled by hand and easy to see. Then hover around the map, or switch to only one model has it to see what the two models do not share.
